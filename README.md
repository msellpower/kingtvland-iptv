
# KINGTVLAND IPTV Portal (v7.0.0)

אתר ריאקט מתקדם לשירות IPTV עם עיצוב חללי, ניהול מנויים ובוט תמיכה מבוסס AI.

## תכונות עיקריות
- **עיצוב מודרני:** שימוש ב-Tailwind CSS עם ערכת נושא כהה/חללית.
- **מנויים דינמיים:** החלפת מחירים בין לקוחות חדשים לקיימים.
- **AI Chatbot:** אינטגרציה מלאה עם Google Gemini (`gemini-3-pro-preview`) למענה אוטומטי ללקוחות.
- **הזמנות:** טופס רכישה ששולח נתונים ישירות ל-Google Sheets.
- **RTL:** תמיכה מלאה בעברית ויישור לימין.
- **PWA:** האתר מוגדר כאפליקציית Web (Progressive Web App) וניתן להתקנה על מסך הבית בנייד.
- **בלוג חדשות:** אגרגטור חדשות קולנוע משולב עם TMDB, כולל טריילרים ופרטים מלאים בתוך האתר.
- **גיבוי Metadata:** רשימת הערוצים נשמרת ב-Local Storage כדי להבטיח זמינות גם כשהשרת איטי.
- **ניהול מרכזי:** כל ההגדרות (מפתחות API, סיסמאות) מנוהלות מגיליון ה-Settings בגוגל שיטס.

## פתרון תקלות נפוצות (Troubleshooting)

### שגיאה: "Exception: אין לך הרשאה להתקשר אל UrlFetchApp.fetch"
שגיאה זו מתרחשת כאשר הסקריפט לא אושר ידנית על ידך בחשבון הגוגל.
**פתרון:**
1. פתח את ה-Google Apps Script Editor.
2. בחר בפונקציה `setup` בתפריט העליון.
3. לחץ על **Run**.
4. אשר את כל ההרשאות בחלונות שיקפצו (ייתכן שתצטרך ללחוץ על Advanced -> Go to ... (unsafe)).
5. בצע Deploy מחדש (New Version) ועדכן את ה-URL.

### הנגן מציג מסך שחור / שגיאת רשת
רוב ערוצי ה-IPTV משדרים ב-HTTP, בעוד האתר מאובטח ב-HTTPS.
**פתרון:**
הנגן באתר מכיל מנגנון אוטומטי שמנסה לעקוף זאת באמצעות פרוקסי (codetabs.com). אם זה עדיין לא עובד:
1. וודא שאתה לא גולש דרך רשת שחוסמת את הפרוקסי.
2. נסה דפדפן אחר.
3. השידור עצמו עשוי להיות לא זמין במקור.

## התקנה והרצה

1. **התקנת תלויות:**
   ```bash
   npm install
   ```

2. **הגדרת API Key:**
   הגדר את המפתח `GEMINI_API_KEY` בסביבת העבודה שלך.

3. **הגדרת Google Sheets:**
   - העתק את הקוד מתוך `code.txt`.
   - פתח Google Sheet חדש -> Extensions -> Apps Script.
   - הדבק את הקוד, שמור.
   - **הרץ את הפונקציה `setup` ליצירת הגיליונות והגדרות ברירת המחדל.**
   - בגיליון **Settings**, עדכן את מפתחות ה-API והסיסמאות שלך.
   - בצע Deploy כ-Web App (גישה ל-Anyone).
   - העתק את ה-URL והגדר אותו כמשתנה סביבה `GOOGLE_SCRIPT_URL` בהגדרות השרת (קובץ `.env` או ב-Settings של הפלטפורמה).

4. **הרצת הפרויקט:**
   ```bash
   npm run dev
   ```

## מבנה מסד הנתונים (Google Sheets)
- **Settings:** הגדרות מערכת (סיסמאות, מפתחות API).
- **Costumers:** רשימת לקוחות פעילים ומנויי ניסיון.
- **Orders:** הזמנות חדשות ותשלומים.
- **Subscribers:** לידים שנרשמו באתר.
- **Reports:** דיווחי תקלות ממשתמשים.
- **SystemLogs:** לוגים של שגיאות מה-Backend.
- **Users:** רשימת משתמשים רשומים.
- **PASSWORD_RESETS:** טוקנים לאיפוס סיסמה.
- **PHONE_VERIFICATIONS:** קודים לאימות מספר טלפון.
- **2FA:** סודות לאימות דו-שלבי.
- **TRUSTED_DEVICES:** מכשירים מהימנים.
