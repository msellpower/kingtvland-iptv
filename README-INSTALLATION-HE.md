# 🚀 מדריך התקנה מלא למערכת KINGTVLAND 🚀

מדריך זה מסביר צעד אחר צעד כיצד לקחת את האפליקציה שהכנו ולהעלות אותה לאוויר (Production) בצורה מאובטחת, חינמית ויציבה לגמרי.

המערכת בנויה בצורה חכמה שמשלבת את היתרונות של:
- **Netlify (גרסה חינמית)**: לאחסון קבצי השרת והאתר. הפניות הגישה ל-API ינוהלו באמצעות Netlify Functions וכך לא נחרוג מכל מגבלה. 
- **Google Apps Script**: כמסד נתונים סודי וחינמי לאיסוף פרטים בגיליונות גוגל אוטומטית.
- **Firebase**: שכבה נוספת ששומרת העדפות והגדרות לסינכרון רציף.

---

## שלב 1: הקמת השרת של Google Apps Script (מסד הנתונים)

קוד ה-Apps Script נועד לנהל ולייצר את כל הגליונות הדרושים אוטומטית, כולל בניית הטריגרים. 
קוד המסד נתונים שלכם הופק ושמור בקובץ `code.txt` בתיקיית הפרויקט.

1. פתחו דפדפן וגשו ל-[Google Apps Script](https://script.google.com/home).
2. לחצו על "New Project" (פרויקט חדש).
3. מחקו את הקוד המוכוון שקיים שם והעתיקו פנימה את **כל** התוכן של הקובץ `code.txt` אל תוך העורך.
4. **עריכת תצורה (Configuration):** הגדירו את שם קובץ הגוגל שיטס בראש הקובץ. לשם כך, צרו קובץ גוגל שיטס חדש תחת החשבון שלכם [כאן](https://sheets.new/), העתיקו את ה-ID שלו מתוך שורת הכתובת (האותיות/מספרים הארוכים בין `/d/` ל-`/edit`) והדביקו אותם במשתנה ה-`SPREADSHEET_ID` שנמצא למעלה בקו הקוד.
5. שמרו את הפרויקט (Ctrl+S).
6. **הפעלת הרצה ראשונית:** למעלה בעורך, בחרו את הפונקציה שנקראת `setup` מתפריט הריצה, ולחצו על הלחצן **Run** (או "הרץ").
   - גוגל יבקש מכם לאשר הרשאות. תאשרו הכל ("Advanced" -> "Go to script (unsafe)").
   - פעולה זו תיצור עבורכם אוטומטית את **כל הגליונות** בגוגל שיטס עם הכותרות שלהם ותייצר טריגרים אוטומטיים עליהם דיברנו שיעבדו פעם ביום לצורך ניקיון הנתונים.
7. **Deploy (פריסה לאינטרנט):** 
   - לחצו על הלחצן הכחול למעלה "Deploy" > "New deployment".
   - לחצו על גלגל השיניים ⚙️ צד שמאל, בחרו `Web app`.
   - בתיאור כתבו: "V1".
   - Execute as: **Me** (האמייל שלכם).
   - Who has access: שנו ל-**Anyone** (חובה כדי ש-Netlify יוכלו לשלוח בקשות).
   - לחצו על **Deploy**.
8. **העתיקו את ה-Web app URL!** הקישור הזה הוא חשוב מאוד וישמש אתכם לשלבים הבאים.

## שלב 2: הרשמה להגדרת הפרויקט ב - Netlify (הפרודקשיין)

מכיוון שאנו מעלים ל-Netlify באחסון החינמי (Free Tier), הגדרנו כבר מראש את תמונת השרת בקובץ ה-`netlify.toml` ותיקיית ה-`netlify/functions/api.ts` כדי לקבל זמינות לפעולות צד-שרת מורכבות ללא צורך בניהול שרת אמיתי, ואו בהוצאות נוספות.

1. הגדירו לכם מאגר (Repository) ב־GitHub, והעלו אליו את כל החומר הקיים של הפרויקט. (Netlify מתחברים ישירות ל-Github שלכם).
2. פתחו את מסך הניהול של [Netlify](https://app.netlify.com/).
3. לחצו על "Add new site" > "Import an existing project".
4. בחרו ב-GitHub, חפשו ובחרו את ה-Repo שלכם.
5. **במסך הגדרות הבנייה (Build Settings):**
   - הכל כבר אמור להיתפס אוטומטית לפי קובץ `netlify.toml`:
   - פקודת בניה (Build command): `npm run build`
   - תיקיית פריסה (Publish directory): `dist`
6. לחצו על **"Show advanced"** ומיד על "New variable" בשביל להכניס את מפתחות הסביבה שלנו לאתר:
   - הוסיפו את המפתח הראשון: 
     - Key: `GOOGLE_SCRIPT_URL` 
     - Value: _**הדביקו כאן את הWebapp URL שהעתקתם מגוגל בסעיף 8.**_
   - הוסיפו את המפתח השני:
     - Key: `NETLIFY`
     - Value: `true` _(זה מחליף את מנוע ה-Vite במנוע של Netlify במצבי Production)_
7. לחצו על כפתור התחתון **Deploy Site**.
8. המתינו כמה דקות - וסיימתם! Netlify יאחסן ויתן לכם כתובת URL לגישה מהירה וחופשית, וגם ישמור שאתם מאובטחים. כל עדכון בגיטהאב, יבוצע גם בנטליפיי אוטומטית.

## שלב 3: הסנכרון של Firebase עם המערכת

האפליקציה מחזיקה בתוכה מנגנון כפול (Dual DB) המאפשר סנכרון ושמירת העדפות של צד־השרת שלנו (כגון מערכת הניהול) מול שירותי Firebase (חינמי גם כן) למידע שלא שייך לאף גיליון.
ההגדרה הזו כבר טבועה בתוך המערכת בקובץ `firebase-applet-config.json` שמגיע עם הפרויקט אשר כבר מוגדר ב-Firestore Rules בצורה קשיחה.

אין צורך בשום התקנה ידנית. אפליקציית הריאקט כבר מוכנה להתחבר ל-Firebase ולמשוך נתונים מסונכרנים לניהול מתקדם של המערכת ב-Netlify.
